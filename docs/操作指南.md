# Better-IN-Q 操作指南

怪物猎人：世界 冰原（15.23.00）的快速重开工具，做成游戏插件：开游戏就在，按 Insert 呼出面板。

## 安装

1. 先装 Stracker's Loader：游戏根目录里要有 `dinput8.dll` 和 `loader.dll`。
   狩技盒子只负责拷文件，不带这个前置；没装的话插件不会被加载。
2. 把压缩包里的 `nativePC` 文件夹整个合并进游戏目录。
3. 进游戏、回到据点时，聊天框会出现「Better-IN-Q 0.7.1 已就绪」。

卸载：删掉 `nativePC\plugins\BetterINQ` 文件夹即可（配置也在里面）。
不要和原版 IN-Q.exe 同时开。

## 第一次进游戏

- 聊天框出现「已就绪」就说明加载成功。
- 如果插件目录旁边（或上一层）有原版 IN-Q 的 `config.txt`，而且你还没有任何套装，
  插件会自动把原版的全套导入一次。
- 之后所有设置都在面板里改，改完立刻生效、自动存盘。

## 打开面板

| 操作 | 键 |
| --- | --- |
| 打开 / 关闭面板 | 键盘 `Insert` |
| 移动光标 | 十字键 / 左摇杆 / 方向键 |
| 确认 | `A`（键盘回车或空格） |
| 返回 | `B`（键盘 Esc） |
| 进左侧栏 | 在内容区往左 |

面板打开时焦点在「重开」上，直接按 A 就重开。
面板开着时游戏收不到键盘、鼠标和手柄，鼠标可以自由移动去点面板。

## 任务页

- 上面是当前要重开的任务，下面是「重开」和「只重置任务」。
- 「换任务」按分组列出所有任务。搜索框支持：

| 输入 | 例子 |
| --- | --- |
| 任务名（中 / 英 / 日） | 传说中的黑龙 / Fade to Black / 伝説の黒龍 |
| 中文拼音与首字母 | heilong、chuanshuo、hl |
| 日文假名与罗马音 | でんせつ、densetsu、kokuryuu |
| 任务 ID | 66845 |

## 套装

「全套」= 装备套装 + 道具套装 + 猫饭 + 任务，重开时一起套用。

| 操作 | 键 / 鼠标 |
| --- | --- |
| 选中 / 进编辑页 | A、空格、回车；鼠标点未选中的行是选中，点已在用的是编辑 |
| 直接套用 | `Y` |
| 改名 | `F` 或手柄 `X`（最多 50 个字，可以重名） |
| 换顺序 | `L3` 或键盘 `E` 进移动模式，上下键换位，再按 `L3`/`A`/`E` 放下，`B` 取消 |

「新建套装」会先让你起名字，留空就用默认名。
套装里的下拉选「—」表示这一项不换。

## 猫饭

每份猫饭记体力、耐力、攻击、防御、属性耐性和三个技能。操作与套装页一致。
如果当前用的那套套装自带猫饭，这一页会显示「这套套装自带猫饭」，
此时列表里的行只能编辑、不能选——套装的猫饭优先。

## 设置

- 界面语言：中文 / English / 日本語（默认跟系统界面语言）
- 重开方式：直接重开 / 重置后回据点再接 / 只接任务不出发
- 翼龙起始、缩短转场黑屏、面板不透明度
- 快捷键三行：重开 / 打开面板 / 只重置任务。选中一格按 A 或点一下，再按想用的键；
  录的时候按手柄 X 或键盘 Delete 是清空这一格
- 存档位：1 / 2 / 3（见下）

## 只重置任务

和原版 IN-Q 的 Reset only 一样：把当前任务重置回据点，不接任务也不出发。
默认没有快捷键，用面板主页的按钮；想用快捷键就到设置页第三行去录。

## 从原版 IN-Q 导入

设置页最下面点「从原版 IN-Q 导入」，在弹出的框里找到 IN-Q 的 `config.txt` 选中。
框从游戏目录开始，左上「上一级」往上退。

导入是整体覆盖，会带过来：全套名、装备套装、道具套装、联动快捷栏、任务 ID、
猫饭、界面语言、重置方式。原版的手柄快捷键不导入。

## 存档位

换成同一台电脑的另一个 Steam 账号，或者同一账号的另一个存档，套装和猫饭都各存各的：
- 账号自动识别，不用管；
- 存档位在设置页点 1 / 2 / 3（游戏里换了存档之后来点一下）。

切换只换套装和猫饭，面板、快捷键、语言这些设置始终跟着你。点当前档不会有动作。

## HDR 显示器

面板颜色会自动适配 HDR。如果偏亮或发灰，把 `BetterINQ.ini` 里 `[General]` 的
`Hdr` 改成 `off` 存盘，下次进游戏生效。

## 遇到问题

| 现象 | 先看这里 |
| --- | --- |
| 没有「已就绪」提示 | 前置 `dinput8.dll` / `loader.dll` 在不在游戏根目录 |
| 面板开着时键鼠还漏进游戏 | 把 `BetterINQ.log` 最后几行发我 |
| 退出游戏后画面没了但没关掉、还有声音 | 等十来秒会自动结束 |
| 面板里打不了中文 / 日文 | 输入法候选条跟着输入框，直接在输入框里打字即可 |

日志位置：`nativePC\plugins\BetterINQ\BetterINQ.log`
